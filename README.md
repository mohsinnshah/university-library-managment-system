# University Library Management System

## Overview & Scope
A comprehensive software project to plan and design a University Library Management System that automates book search, issue/return processes, reservations, and member administration.

## Project Objectives
- Streamline library operations for students, faculty, and librarians.
- Implement efficient UML modeling and clickable UI prototypes.
- Maintain clear software requirements documentation using IEEE/ISO SRS principles.

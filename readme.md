University Library Management System
Project Description

This project aims to develop a system to manage university library books, students, book borrowing, returns, and overdue records.

Objectives
Manage book records and library members.
Track book borrowing and returns.
Search for books easily.
Manage due dates and overdue books.
Improve library efficiency.
Project Scope

The system will manage books, members, borrowing, returns, and basic library reports.

Assumptions
Students and library staff will use the system.
Internet access and computers are available.
Library records are provided accurately.
Constraints
Limited time and resources.
Fixed project deadline.
User data must remain secure.
